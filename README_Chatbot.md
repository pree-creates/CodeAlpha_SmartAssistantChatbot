# Smart Assistant Chatbot

## About the Project
Smart Assistant Chatbot is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Internship.

It interacts with users through the console and provides basic assistance using predefined commands.

## Features
- Personalized greeting
- Displays current date and time
- Tells random programming jokes
- Performs basic mathematical calculations
- Provides information about Python and modern technologies
- Displays available commands
- Handles invalid inputs and unknown commands

## Technologies Used
- Python
- Random module
- Datetime module

## Concepts Used
- Functions
- While loops
- If-elif-else statements
- Dictionaries
- Lists
- Exception handling
- User input and output

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python chatbot.py
```
